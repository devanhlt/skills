# Game development

Unity studio workflows and reusable game-design guidance.

## User-invoked

No imported skills require explicit-only invocation.

## Model-invoked

- **[ccgs-brainstorm](./ccgs-brainstorm/SKILL.md)**: Develop an idea into a structured game concept.
- **[ccgs-code-review](./ccgs-code-review/SKILL.md)**: Review game code for architecture, quality, and testability.
- **[ccgs-consistency-check](./ccgs-consistency-check/SKILL.md)**: Find inconsistent entities, values, and rules across designs.
- **[ccgs-create-architecture](./ccgs-create-architecture/SKILL.md)**: Translate game designs into a technical architecture.
- **[ccgs-create-epics](./ccgs-create-epics/SKILL.md)**: Turn approved designs and architecture into epics.
- **[ccgs-design-system](./ccgs-design-system/SKILL.md)**: Write a game design document for one system.
- **[ccgs-learn](./ccgs-learn/SKILL.md)**: Extract and review reusable lessons from completed work.
- **[ccgs-map-systems](./ccgs-map-systems/SKILL.md)**: Map game systems, dependencies, and design priorities.
- **[ccgs-propagate-design-change](./ccgs-propagate-design-change/SKILL.md)**: Trace design revisions into affected architecture decisions.
- **[ccgs-resume-session](./ccgs-resume-session/SKILL.md)**: Resume work from saved session state and verify it against files.
- **[ccgs-reverse-document](./ccgs-reverse-document/SKILL.md)**: Recover design or architecture documentation from existing code.
- **[ccgs-save-session](./ccgs-save-session/SKILL.md)**: Save project decisions, evidence, blockers, and the next step.
- **[ccgs-sprint-plan](./ccgs-sprint-plan/SKILL.md)**: Create or update a sprint plan from project capacity and priorities.
- **[ccgs-start](./ccgs-start/SKILL.md)**: Find the right starting point for a Unity game project.
- **[ccgs-story-done](./ccgs-story-done/SKILL.md)**: Check acceptance criteria and finalize a completed story.
- **[ccgs-story-readiness](./ccgs-story-readiness/SKILL.md)**: Check whether a story is sufficiently specified to implement.
- **[game-design-and-rewards](./game-design-and-rewards/SKILL.md)**: Design and review mechanics, player experience, progression, and rewards.
- **[query-me](./query-me/SKILL.md)**: Clarify hidden requirements through a structured interview.
- **[story-review-test-fix](./story-review-test-fix/SKILL.md)**: Compare implementation and tests with a written story specification.
- **[unity-bug-root-cause](./unity-bug-root-cause/SKILL.md)**: Trace a Unity gameplay defect to its originating trigger.
- **[unity-clean-architecture-review](./unity-clean-architecture-review/SKILL.md)**: Review separation of Unity presentation, domain, and infrastructure.
- **[unity-tdd-workflow](./unity-tdd-workflow/SKILL.md)**: Implement Unity gameplay rules through test-first development.

Use full `ccgs-*` names to distinguish studio workflows from engineering skills with similar names. The imported pipeline references `create-stories` and `dev-story` as conceptual steps; dedicated skills with those names are not supplied. Use the documented manual fallback or `unity-tdd-workflow` where appropriate.
